# NumberDetectionModel

Цель этого проекта написать простую нейросеть классификации рукописных цифр используя **только нативные средства python**

## Dataset
Датасетом для этого проекта выступил `csv` файл с разметкой, так как `python` нативно поддерживает работу с этим форматом данных.

``` txt
Формат CSV-файла:
- Каждая строка представляет собой одно изображение.
- Первый элемент строки — метка (label), соответствующая классу изображения.
- Остальные элементы строки — значения пикселей (0–255), представляющие изображение.
```

## Layer

### Neuron

Класс представляет собой нейрон в нейросети.

Содержит в себе следующие аттрибуты:
- **weights** - список весов(изначально содержит случайные числа от -0.5 до 0.5)
- **bias** - смещение нейрона
- **inputs** - список входных значений
- **output** - выходное значение после применения функции `activate`
- **delta** - значение ошибки для дальнейшей коректировки весов
- **activation** - функция активации для вычисления входного значения(`softmax` или `relu`)
- **dropout** - вероятность отключения нейрона
- **dropped** - булево значение показывающие сработал ли `dropout`

Функции:
- **activate** - принимает входные данные и обрабатывает с учетом типа активации(`relu` или `softmax`).
- **derivative** - метод для опеделения производной функции активации

### Layer

Класс представляет собой слой нейронов, состоящий из нескольких нейронов.

Содержит в себе следующие аттрибуты:
- **neurons** - список нейронов в слое
- **activation** - функция активации для слоя

Функции:
- **forward** - принимает входные данные и передаёт каждому нейрону слоя, при `softmax` нормализует выходные значения, так что бы в сумме они давали 1.

## Network

Класс `Network` представляет собой нейронную сеть, которая поддерживает обучение с использованием обратного распространения ошибки и предсказаний на основе `softmax`, который подходит для многоклассовой классификации.

Содержит в себе следующие аттрибуты:
- **layers** - список слоёв нейросети

Функции:
- **forward** - метод для распространения прямого распространения данных через сеть
- **backward** - метод для обратного распространения ошибки и обновления весов сети
- **train** - основной метод для тренировки нейросети
- **predict** - метод получения предсказания на уже натренированой сети

## Serialization
Файл `serialization.py` содержит в себе 2 функции `save_model` и `load_model`.
Первый сохраняет `weights` и `bias`(остальные параметры временные или меняются) в `json` файл(так как работу с ним python поддерживает нативно), а второй создаёт класс Network на основе данных из `json`.
